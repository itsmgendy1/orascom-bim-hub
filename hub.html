Export server auto-sync

Pulls the newest nightly exports (serve_exports.py) into Data Center and queues them to every module automatically. Mapping modules wait at their mapping screen; Naming and Model Quality run immediately.

Autodesk Forma file import · no account needed

Export Area metrics / Units from Forma (CSV) and drop the file in the Data Center — the Hub detects it and saves the figures to the active project. Works offline, from file://, with zero accounts or tokens.

Advanced: live API link (optional, free APS read APIs)

Needs a free APS app (Client ID) and the Hub served over HTTP — login does not work from file://. Tokens stay in this browser; Disconnect wipes them.
