📖 Authoritative Naming Rules (read-only reference)

Source of truth: Naming Convention.png (MODON p.58) for segment patterns · QAQC Checklist workbook (P0152-K00146-OCC-UB01-ZZ-QAQC-ZZ-000001.xlsx) for compliance obligations · 18 Model Checker HTML reports for observed codes. Strict mode: every non-conforming name is FAIL (no warnings for legacy content).

Family PNG

OCC - CategoryAbb - TypeAbb - Description

e.g. OCC-Wall-W01-200mm → real data OCC-DECP-WF04-OIL-BASED-PAINT-2MM. Min 4 hyphen tokens, UPPERCASE, - only. QA: QA-AR-014.

Workset PNG

Discipline - Category

e.g. ST - ST Framing, AR - Walls. 2-letter discipline + - + category. QA: QA-GE-019/020/021.

Views PNG tree

00_OCC - SHOP DRAWINGS - VIEWS, 01_OCC - COORDINATION - VIEWS, 02_OCC - NAVISWORKS - VIEWS, 03_OCC - IFC - Views. Personal {3D - user} / Copy / lowercase working views FAIL. QA: QA-GE-023/024/025.

View Templates observed

OCC-VTE-<DESCRIPTION>

e.g. OCC-VTE-3D-BLOCKWORK-DETAILS. Scale suffixes (/), -01 duplicates FAIL strict.

Materials PNG

OCC - MaterialAbb - MaterialType

e.g. OCC-ST-LIMESTONE. QA: QA-GE-050.

Schedules PNG

OCC - Bldg - Disc - Category · zones/ID: OCC - Bldg - SubZone - Disc - Category

e.g. OCC-HT01-ST-ST Framing, OCC-HT01-EXECUTIVE SUITE-ID-CEILING. QA: QA-GE-033/034.

Datum observed
